# Shared game events

Use ready, playing, won and lost phases. The approved game's capability profile defines its objective and failure rules: do not impose star collection, portals or a timer on other genres. Freeze gameplay after won/lost and reset resources on restart. Emit immutable presentation events for pickups, damage, spells, attacks and endings. Audio/VFX reflect events without changing gameplay state. Interface changes require coordinated revisions and renewed checks.
