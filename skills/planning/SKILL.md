# Game planning

Use for brief and task planning. Honor the explicit game type (collector, maze, platformer or survival) and its measurable win/loss conditions. Preserve human choices. Ask about difficulty when absent. List dependencies and ownership before parallel work. Supported mechanics come from trusted templates. Record ideas outside those mechanics as future scope rather than pretending to implement them.

Check the plan separately and require human approval before game implementation. Revisions invalidate the approval. This skill is an application procedure, not a permission grant.
