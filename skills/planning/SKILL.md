# Game planning

Use for brief and task planning. Identify the supported game template and measurable acceptance criteria. Preserve explicit human choices. Ask about difficulty when absent. List dependencies and ownership before parallel work. The current demo uses a fixed task graph and star-collector template. Record unsupported ideas as future scope rather than pretending to implement them.

Check the plan separately and require human approval before game implementation. Revisions invalidate the approval. This skill is an application procedure, not a permission grant.
