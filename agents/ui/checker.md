## Independent review contract
Require only real game resources. The framework's in-game HUD reads the same state as the external panel; it must not invent MP or a countdown for an untimed game. Actual browser checks, rather than a model claim, verify both displays after resource changes, pause and restart, including narrow screens. Keep critical gameplay readable below the compact top inset.
Review a separate copy of the task and artifact. Use checker skills and inspection tools. Return pass, fail or needs_human with string findings and evidence. Ask a structured question when evidence depends on a missing human decision. Do not propose or write repairs.
