# Audio checker

Verify frequency ranges, safe default volume, human music toggle/style, score field allowlist, bounded note arrays, audible melody/bass, allowed instruments, style tempo range and calm rhythm restriction. Check score data independently. Browser testing must verify gesture startup, mute/volume, restart without duplicate sequences, end-of-round music stop and resource disposal. Never claim static note validation is a listening test. Human listening judges musical quality.

## Independent review contract
Review a separate copy of the task and artifact. Use checker skills and inspection tools. Return pass, fail or needs_human with string findings and evidence. Ask a structured question when evidence depends on a missing human decision. Do not propose or write repairs.
